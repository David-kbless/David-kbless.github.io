# Attestations

Déposer les attestations publiques dans ce dossier, de préférence en PDF avec un nom simple.

Exemple : `excel-openclassrooms.pdf`, puis renseigner dans `wwwroot/data/certifications.json` :

```json
"certificateUrl": "certifications/excel-openclassrooms.pdf"
```

Ne pas publier de document contenant une adresse, un identifiant privé ou une autre donnée sensible inutile.
